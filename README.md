# Gnomintosh-Tahoe
Gnomintosh (Tahoe version) is a customization theme package that transforms the GNOME desktop environment to look like macOS Tahoe.

## Features
* **Liquid Glass UI: Mimics** macOS transparency and blur effects on panels and menus.
* **GNOME Compatibility:** Built to support modern GNOME desktop versions.
* **Apple Layout:** Moves controls to a global top bar and adds a bottom application dock.
* **Custom Assets:** Includes matching icon packs, window controls, and sleek fonts.

## How to install?
Install the extension from the "Extension" folder, download it. Then download the config from the "dconf" folder. and place it in your home directory. Enter the command: dconf load /org/gnome/shell/extensions/ < extensions.dconf
then download the wallpaper
Then open the "logo menu" extension settings and download the logo of your choice from the "logo" folder and place it in the logos
then download the icons and theme below in "Credits"
